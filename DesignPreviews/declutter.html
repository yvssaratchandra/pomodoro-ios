Review routes & implementation constraints

Try: Project settings → Daily goal → change the schedule → Back → Save. Then Stats → choose Work. Switch to All projects to see the target disappear. From Focus, start a session → tap ◐ → tap the dim screen → add a thought → Done. An empty dismissal starts the same ten-second return delay.

Project edits: name, status, durations and goals share one draft and one Save. Back from a detail editor keeps the draft; Cancel leaves the project unchanged. New projects still require only a name. Project-specific goal calculations, saved-only totals, historical revisions and all backup data remain intact.

Native behavior: real countdowns, background notifications, system share sheets, signing, widgets and Live Activities require the existing iOS implementation and device testing. The preview does not claim to simulate those services. Rest days, scheduled weekly changes and the one-time assignment of an old global goal remain available.

Visual review: this is an HTML approximation of native controls, not a pixel-identical SwiftUI render. Keep the current timer logic, Dim Focus brightness/update frequency, privacy defaults and ten-second return when implementing the approved layout.
