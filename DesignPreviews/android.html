Design foundations

Keep the app recognisable.

Reuse the same hierarchy and components. Android supplies the navigation, permissions, file picker, and notification controls.

Colour and surfaces

Focus#6860D8
Break#4E6B56
Dark break#84A08C

Soft lavender background and white cards in light mode. Black canvas and raised charcoal cards in dark mode. Colour reinforces labels; it never carries meaning alone.

Type and spacing

25:00 Tabular timer

Android system type for interface text; monospace digits for time. Use a 20 dp page inset, 18 dp card corners, and controls at least 48 dp high. Larger text replaces the timer ring with a linear indicator.

One navigation model

FocusThoughtsStats

Three persistent destinations. Projects and Settings open from Focus. Android Back dismisses the top editor, returns from a project detail, then returns from Projects or Settings.

Save without surprises

Project settings save together. Each accepted plan task and thought saves immediately. Unsubmitted text stays a draft; dirty dismissal asks before discarding. A failed save retains the editor and text.
