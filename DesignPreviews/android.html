What changes

Hierarchy before decoration.

The timer becomes tappable. Plans collapse into a single row. Thoughts becomes a list again. Projects and Settings use grouped navigation instead of stacks of large cards and buttons.

One component vocabulary

Primary-colour timer digits, indigo progress, blue actions, sage breaks, restrained red destructive controls. Rounded rectangles, subtle separators, compact tabs, and black dark-mode surfaces.

Practical platform differences

Use Android system fonts and supported Compose controls. Permissions, notifications, file pickers, keyboard and system navigation remain Android-owned. No Apple font assets or custom imitation control toolkit.

Review before app changes

This is the design review stage. The Android app has not been restyled yet. Review ready/running Focus and Thoughts first, then open Projects, Settings and the editors.

Try tapping the timer, opening a session plan, editing project goals, and cancelling a changed draft. Timers are frozen; sample edits stay in the preview.
